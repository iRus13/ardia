# Profile symbols

The planet, campfire, pizza and skull silhouettes are the filled Phosphor Icons artwork from https://github.com/phosphor-icons/core/tree/main/assets/fill . Their original SVG source is retained next to the PNG used by React Native. PNGs were rasterized at 96 × 96 without changing the geometry. The source filenames were planet-fill.svg, campfire-fill.svg, pizza-fill.svg and skull-fill.svg.

Copyright (c) 2023 Phosphor Icons. These four icons are MIT licensed; see LICENSE.phosphor.

These supplement the system SF Symbols for shapes unavailable as SF Symbols on macOS. Existing stored symbol identifiers remain unchanged.
